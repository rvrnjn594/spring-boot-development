# Final Remarks

Here's a quick summary of what we learned from the "OAuth2 with Spring Security" module.

> We'll cover the following:
>
> - Summary
> - Takeaways

## Summary

This module started with a comprehensive description of the theory behind OAuth2.  
We covered the various types of grants that manage access to protected resources. The latter half of the module focused on implementing these concepts in practical exercises to give a vivid idea of how authentication works.  
 In the end, we learned how to enable third-party authentication in our application.

## Takeaways

- We learned how to use Spring framework in the development process.
- We comprehensively discussed the fundamentals of Spring Boot (auto-configuration, database integration, web services) and its advantages over the conventional architecture.
- We learned all the essential concepts needed to start developing an application using Thymeleaf and Spring Boot.
- We learned how to build a full-reactive system using a programming strategy leveraged by Spring WebFlux.
- We learned how to implement and use the OAuth2 authentication process.
